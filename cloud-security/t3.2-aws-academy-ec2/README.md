# T3.2 AWS Academy

Wednesday, 11 Mar 2026

*Originally published on my UNSW OpenLearning blog.*

In lab 3 of module 6, i was taught how to create, manage and configure an Amazon EC2 instance. I learnt the basics like what it was and how it worked, allowing me to understand how web-scale cloud computing is made easier for web developers.

One skill I learnt was how to monitor performance and system status with Amazon CloudWatch, allowing me to see the metrics for my EC2 instance. It allowed me to check system logs and resource usage, allowing me to troubleshoot.

An important concept I learnt was how security groups work as a virtual firewall. Through the lab, if I didn't modify the security group rules, port 80 would have been blocked. This showed me how security groups can restrict network traffic within an instance.

Overall a great lab that strengthened my understanding of EC2 instances.
