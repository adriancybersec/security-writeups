# Security Write-ups

Hi, I'm Adrian Chan, a Bachelor of Cyber Security student at UNSW Sydney (2025–2028). This repo collects my write-ups from coursework, labs and challenges. It covers web exploitation (XSS, SQL injection and auth/MFA bypass with Burp Suite), Hack The Box labs, OSINT, and AWS cloud security (IAM, assume-role, VPC/EC2 and CloudSploit).

Each write-up was first published on my UNSW OpenLearning blog. The text is as I wrote it then.
